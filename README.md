# CAT CNC — Manutenção Industrial

Landing page em React e Vite. As fotos de oficina, equipamentos e sede vieram do acervo do site anterior. As versões WebP e o símbolo da marca ficam em `public/media/`.

## Rodar localmente

Com Node.js 22.12 ou superior, instale as dependências e abra a URL exibida pelo Vite.

```sh
npm ci
npm run dev
```

Para conferir a compilação de produção, rode `npm run build` e `npm run preview`. O build estático fica em `dist/`.

Os textos, serviços, fotos da galeria e contatos ficam em `src/main.jsx`. O botão de orçamento abre o WhatsApp comercial da CAT CNC.
